## 💡 How I work

- **Talk to the user first.** I read the customer's real spreadsheets, quote PDFs and inboxes before I design anything.
- **Safe by default.** Every agent that can email or call someone ships with a dry-run mode, a human review gate and a kill switch. Nothing goes out until it has been reviewed.
- **No fake data in front of customers.** Demos use clearly marked sample data, and production runs on real records only.
- **Small, reversible deploys.** Live systems change often and safely.
